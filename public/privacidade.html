Política de privacidade — Radar Estudio

Atualizada em 25 de outubro de 2026

O que é

O Radar Estudio é uma ferramenta pessoal que lê estatísticas dos canais do YouTube do próprio dono do app, para acompanhar o desempenho dos vídeos. Ele não é oferecido a outras pessoas.

Dados que acessa

  • Somente leitura, pelos escopos youtube.readonly e yt-analytics.readonly.
  • Estatísticas dos canais autorizados: visualizações, retenção, inscritos, fontes de tráfego e dados públicos dos vídeos.
  • O app não publica, edita nem apaga nada no YouTube.

Como guarda e usa

  • Os dados e os tokens de acesso ficam só no computador do dono, com acesso restrito.
  • Nada é vendido, compartilhado com terceiros nem usado para publicidade.
  • O uso dos dados do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Os dados guardados localmente são apagados junto.

Contato

Pelo e-mail de suporte exibido na tela de consentimento do Google.

English: Radar Estudio is a personal, read-only tool that reads YouTube statistics for its owner's own channels. Data and tokens stay on the owner's computer, are never sold or shared, and Google user data is used in line with the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at any time at myaccount.google.com/permissions.
